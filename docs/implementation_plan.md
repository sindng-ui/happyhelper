# 📑 설정 실시간 자동저장 & 앱 재시작 시 마지막 설정 복원 포함 프리셋 구현 계획서

형님, **설정을 수정하는 순간 즉시 실시간 자동 저장(Auto-Save)**되고, **앱을 종료했다가 재실행해도 마지막으로 열어두었던 설정이 100% 그대로 로드**되도록 요청사항을 보완한 구현 계획서입니다! 🐧✨

---

## 💡 보완된 핵심 요구사항

1. **⚡ 실시간 자동 저장 (Auto-Save)**:
   - 스킬 슬롯 켜기/끄기, 주기 숫자 수정, 핫키 변경, 일시정지 키 추가/삭제 등 **UI에서 설정을 변경하는 즉시 `config.json` 및 현재 선택된 프리셋 파일로 자동 실시간 저장**됩니다.
   - 별도의 "저장" 버튼을 누르지 않아도 모든 변경사항이 즉각 반영됩니다.

2. **🔄 앱 재시작 시 마지막 설정 그대로 자동 로드**:
   - `config` 구조에 `activePreset` (마지막으로 선택된 프리셋 이름) 정보를 함께 보관합니다.
   - 앱을 껐다 다시 실행하면, **마지막에 사용하던 프리셋 이름과 해당 프리셋의 스킬 세팅이 100% 그대로 복원**되어 드롭다운에 선택된 상태로 로드됩니다.

3. **📍 위치 및 드롭다운 선택 동작**:
   - 부가 옵션 카드 바로 아래에 `설정 프리셋 (저장 / 불러오기)` 카드를 배치합니다.
   - 드롭다운에서 다른 항목을 클릭하는 것만으로 해당 프리셋으로 즉시 전환됩니다 (가져오기 버튼 불필요).
   - `+` 버튼으로 새 이름(예: `함성바바`, `회오리드루`)을 입력받아 현재 세팅을 새 프리셋으로 저장합니다.
   - 🗑️ 버튼으로 선택된 프리셋 삭제를 지원합니다.

## 🛠️ 변경 대상 파일 명세

### 1. `src-csharp/ConfigManager.cs` & `MainWindow.xaml.cs`
- `AppConfig` 구조에 `activePreset` 필드 추가.
- `ConfigManager.cs`: `DeletePreset(name)` 추가.
- `MainWindow.xaml.cs`: `deletePreset` IPC 핸들러 및 `activePreset` 호환성 지원.

### 2. `renderer/tauriBridge.js`
- `window.api.deletePreset(name)` 메서드 연결.

### 3. `renderer/index.html` & `renderer/index.css`
- `preset-card` 카드를 부가 옵션 하단에 배치.
- 드롭다운, `+` 생성 버튼, 🗑️ 삭제 버튼 스타일 적용.
- 프리셋 이름 입력을 위한 깔끔한 커스텀 모달 `#presetInputOverlay` 신설.

### 4. `renderer/app.js`
- `saveConfigAuto()`: 설정 변경 시 `saveConfig` 및 `savePreset` 실시간 자동 호출.
- `loadPresetList()`: 저장된 프리셋 목록 렌더링 및 `activePreset` 자동 선택.
- 드롭다운 `change` 이벤트: 선택된 프리셋으로 즉시 전환 및 `activePreset` 업데이트.
